# Portfolio

A simple personal portfolio website.

## Files

- **index.html** - Main HTML file
- **style.css** - Styling for the portfolio

## Getting Started

1. Open `index.html` in your web browser to view the portfolio
2. Edit `style.css` to customize the styling
3. Modify `index.html` to add your content

## Features

- Clean and simple design
- Responsive layout with CSS styling
